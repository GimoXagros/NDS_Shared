# NDS_Shared

Shared code for all my emulators on the Nintendo DS

## This fork and integration

This is the GimoXagros fork of [FluBBaOfWard/NDS_Shared](https://github.com/FluBBaOfWard/NDS_Shared), used by the custom [NitroSwan](https://github.com/GimoXagros/NitroSwan) build. It is shared source code, not a standalone NDS application, and this fork has no GitHub Release binaries.

NitroSwan pins `source/Shared` to a specific commit, which can differ from this repository's `main`. Clone the consuming emulator with recursive submodules; `Unzip` is itself a submodule. See the [NitroSwan development guide](https://github.com/GimoXagros/NitroSwan/blob/main/Docs/DevelopmentGuide.md). Keep the recorded gitlinks when reproducing a release instead of updating dependencies to their latest branches.
